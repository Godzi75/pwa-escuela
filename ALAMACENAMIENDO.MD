Tipos de almacenamiento con JavaScript:
    *localStorage: Sirve para conservar inforamcion sencilla por medio de una clave:valor.
    *sessionStorage: Sirve para almacenar informacion durante la sesion.
    *IndexdDB: Sirve para almacenar cantidades mas grandes de inforamcion, es estructurada con indices 
    *Cache storage API: Sirve para conservar solicitudes HTTP y recursos que la misma aplicacion necesita, especialmente cuando trabajos offline.

    Nota: Estos tipos de almacenamiento pertenecen al entorno del navegador
